DESIGN LOCK

三视图，是角色不走样的唯一基准

正面、右侧、背面统一比例和基线。建模先锁定轮廓与侧向厚度，再处理表情、材质和细节；后续只改用户点名的问题，不重新设计已确认部分。

REAL OUTPUT

从手机画面到动作录屏，看到真实运行结果

REPEATABLE WORKFLOW

替换角色，不必重造流程

Skill 把不可省略的验收门槛写成清单和校验器；角色可以千变万化，交付质量保持一致。

  1. 01

    锁定设计

    生成或导入严格三视图，记录比例、颜色、材质和禁止项。

  2. 02

    Blender 建模

    建立可编辑源文件、单根骨架与网页友好的网格和材质。

  3. 03

    动作制作

    基础九动作保持稳定，眨眼、蹦跳、调皮等动作按角色扩展。

  4. 04

    三轮比对

    依次校正轮廓、侧背面细节、材质和动作穿插，不改已确认结构。

  5. 05

    网页与语音

    输出框架无关插件，接入浏览器语音或宿主私有 ASR / TTS。

  6. 06

    MCP 与验收

    通过本机 MCP 控制动作，用真实浏览器、模型校验器和哈希完成交付。
