# 橙子精灵设计锁定

唯一设计基准为 `assets/reference/orange-spirit-three-view.png`，建模和后续修改不得脱离正面、右侧与背面三视图自行创新。

- 主体：略扁的橙子球体，底部轻微压平；暖橙主色，表面为密集、不规则、离散的细小油胞颗粒。
- 五官：纵向深棕椭圆眼，浅粉椭圆腮红，细深棕微笑嘴；眨眼时眼睛收窄但不消失。
- 四肢：短小水滴形双臂与贴地圆润双脚，尺寸和锚点保持左右协调。
- 果梗：短圆柱棕色果梗，位于顶部中央并遮住叶片根部。
- 叶片：两片长椭圆尖叶，沿长度上拱、横向浅杯状，具可见厚度；中央主脉贯穿，侧脉贴面展开，正反面均可读。
- 禁止：光滑塑料球、连续虫纹、扁平无厚度叶片、叶根悬空、眼睛完全消失、未经参考支持的装饰或结构。
